01 — Tokens

Colour

One accent, one brand colour, nine neutrals and three semantic states. Indigo is only ever interactive: a link, a focus ring, a selected chip, a primary button. Decorative indigo is a defect.

04 — Depth

Elevation

Surfaces rest flat. Shadow exists only as feedback — hover, focus, or a floating layer. A static card with a shadow is a bug.

Card on hover0 8px 30px rgba(0,0,0,0.08) · lift 2px

Hover state

Hovering lifts the card 2px and adds a soft, low-opacity shadow. 200ms, ease-out.

Primary button glow0 4px 12px rgba(99,102,241,0.35)

Only the primary button gets a tinted glow — never a secondary or ghost.

Floating layer0 16px 40px rgba(0,0,0,0.12)
Focus ring0 0 0 3px rgba(99,102,241,0.12)

Focus is a ring, not a shadow. It never moves the layout.

06 — Documentation

The DESIGN.md format

One markdown file, seven sections, no build step. It renders on GitHub, diffs cleanly in review, and gives a model exactly the context it needs to produce matching UI.

genesis.design.md 
# Genesis

## Overview
An editorial precision interface for a community
platform where developers discover, share and
download design system files.

## Colors
- **Primary** (#6366F1): CTAs, active states, links
- **Surface** (#FFFFFF): cards, panels, nav backdrop
- **Border** (#E8E8EC): card borders, dividers

## Typography
- **Display**: General Sans, 72px, 700, -0.04em
- **Body**: DM Sans, 15px, 400
- **Code**: JetBrains Mono, 12px, 400

## Spacing
- Base 4px · scale 4, 8, 12, 16, 20, 24, 32…
- Container 1280px · gutter 24px

## Components
- **Buttons**: 6px radius, 38px height, four variants
- **Cards**: 12px radius, 1px border, flat until hover

## Elevation
Cards gain 0 8px 30px rgba(0,0,0,0.08) on hover.

## Do's and Don'ts
- Do keep indigo for interactive elements only.
- Don't use shadows on static elements.

07 — Governance

Rules

A kit is only useful if it can say no. These five rules decide the close calls.

Do
  • Use indigo (#6366F1) only for interactive elements — never for decoration or static text.
  • Maintain the 4px spacing grid for all padding, margins and gaps.
  • Use General Sans for headings and DM Sans for body — never swap them.
  • Keep kit cards at 12px radius and buttons/inputs at 6px.
  • Provide sufficient contrast in both light and dark modes — test both.
Don't
  • Don't use pure black or pure white for text — use the defined palette values.
  • Don't add decorative gradients or illustrations — the interactive dot grid is the only decorative element.
  • Don't use shadows on static elements — reserve elevation for hover and focus states.
  • Don't use more than two font weights on a single screen.
  • Don't place more than one primary button in the same view section.
